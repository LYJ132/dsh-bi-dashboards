## ⚠️ 需要手动操作

### Docker 镜像配置生效
由于 Docker Desktop 的网络隔离，daemon.json 配置无法自动生效。请按以下步骤操作：

1. **打开 Docker Desktop Settings**
   - 右键系统托盘鲸鱼图标
   - 点击 Settings (齿轮图标)

2. **配置 Docker Engine**
   - 左侧选择 **Docker Engine**
   - 将以下内容粘贴到 JSON 编辑器：
   ```json
   {
     "registry-mirrors": [
       "https://docker.mirrors.ustc.edu.cn",
       "https://hub-mirror.c.163.com",
       "https://mirror.baidubce.com"
     ],
     "dns": [
       "223.5.5.5",
       "114.114.114.114",
       "8.8.8.8"
     ]
   }
   ```
   - 点击 **Apply & Restart**

3. **验证配置**
   ```powershell
   docker info | Select-String "Registry Mirrors"
   docker info | Select-String "DNS"
   ```

### WSL DNS 配置（可选）
1. 以管理员权限打开 PowerShell
2. 运行：
   ```powershell
   echo "[network]" | Out-File -FilePath C:\Users\LIN YU JIAN\AppData\Local\WSL\wsl.conf -Encoding utf8
   echo "generateResolvConf = false" | Out-File -FilePath C:\Users\LIN YU JIAN\AppData\Local\WSL\wsl.conf -Append -Encoding utf8
   echo "" | Out-File -FilePath C:\Users\LIN YU JIAN\AppData\Local\WSL\wsl.conf -Append -Encoding utf8
   echo "[dns]" | Out-File -FilePath C:\Users\LIN YU JIAN\AppData\Local\WSL\wsl.conf -Append -Encoding utf8
   echo "nameserver = 223.5.5.5" | Out-File -FilePath C:\Users\LIN YU JIAN\AppData\Local\WSL\wsl.conf -Append -Encoding utf8
   echo "nameserver = 114.114.114.114" | Out-File -FilePath C:\Users\LIN YU JIAN\AppData\Local\WSL\wsl.conf -Append -Encoding utf8
   echo "nameserver = 8.8.8.8" | Out-File -FilePath C:\Users\LIN YU JIAN\AppData\Local\WSL\wsl.conf -Append -Encoding utf8
   wsl.exe --shutdown
   ```
3. 重新启动 WSL
