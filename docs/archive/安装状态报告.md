## ⚠️ 需要手动操作

### Docker Desktop 启动
Docker Desktop 已安装但需要手动启动：
1. 在 Windows 开始菜单搜索 "Docker Desktop"
2. 启动 Docker Desktop
3. 等待系统托盘图标显示为绿色（运行中）

### 配置 WSL2 集成
1. 打开 Docker Desktop Settings
2. 进入 Settings → General
3. 勾选 "Use WSL 2 based engine"
4. 进入 Settings → Resources → WSL Integration
5. 勾选 "Ubuntu-22.04"
6. 点击 "Apply & Restart"

### 验证 Docker
启动后在 PowerShell 中运行：
```powershell
docker ps
docker info | grep -A 5 "Registry Mirrors"
```

## ⏳ 等待数据主机连接

当您在局域网内连接数据主机 (192.168.120.192) 后：
1. 在数据主机上运行：`cd bi-plugin && docker compose up -d`
2. 在本机重启 DSH
3. 验证连接：`curl http://192.168.120.192:8600/api/meta/tables`
